# Homebrew Tap

Homebrew formulae for [sadopc](https://github.com/sadopc) projects.

## Install

```bash
brew tap sadopc/tap
brew install godu
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [godu](https://github.com/sadopc/godu) | Fast, interactive disk usage analyzer for the terminal |
